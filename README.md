# 기억 — 한국건축 아카이브

구석기부터 동시대까지 한국 건축·생활문화·지역 특색을 비교하는 한국어 학습 웹사이트입니다.

배포 주소: [architect-history.vercel.app](https://architect-history.vercel.app)

## 실행

Node.js 22 이상에서 별도 패키지 설치 없이 실행합니다.

```sh
npm run dev
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다.

## 기능

- 독립 HTML 73페이지: 시대·지역·기능·종류별 목록과 건축 상세·비교·학습 페이지
- 접고 펼칠 수 있는 좌측 패널, 현재 분류 강조, 데스크톱 숨김 상태 기억
- 모바일 오버레이 메뉴, 바깥 영역·Esc로 닫기, 키보드 포커스 관리
- 10개 시대, 6개 주요 권역과 관련 문화권, 7개 기능, 12개 종류
- 목록 안에서 검색·시대 선택·정렬·페이지 번호로 탐색
- 23개 건축 기록, 창건·재건·복원 구분, 구조·재료·공간·문화 비교
- 보관함과 관찰 메모, 출처 자료실, 건축 용어집, 해설 퀴즈

## Vercel 배포

실제 배포 소스는 `web/`에 있습니다. 일반 Git 파일로 추적하므로 원격 저장소에도 스크립트·스타일·이미지가 포함됩니다. 기존 Sites 전용 체크아웃 `site/`는 별도 저장소이므로 이 저장소에서 제외합니다.

`vercel.json`에서 다음 설정을 명시합니다.

- 빌드: `npm run build && npm run check`
- 출력 폴더: `web/dist`
- 프레임워크: 정적 웹사이트
- 디렉터리 주소: `/types/`, `/regions/jeju/`, `/buildings/changdeok/` 등

HTML과 빌드별 실행 파일은 빌드 시 생성되며 Git에서는 제외합니다. `web/dist/` 최상위의 JS·CSS와 `web/dist/assets/`는 빌드 입력이므로 반드시 Git에 포함해야 합니다. 이미지 URL은 `/assets/...` 절대 경로를 사용합니다. 메뉴 코드는 본문 기능 모듈과 독립적으로 실행되며, 실행 파일은 빌드별 경로로 묶어 이전 캐시와의 혼용을 예방합니다.

## 자료와 이미지

국립중앙박물관, 국가유산청, 국사편찬위원회, 서울역사박물관, 속초시립박물관, UNESCO 등의 공개 자료를 요약·재구성했습니다. 대표 사례를 통한 학습용 아카이브이며 전수조사는 아닙니다. 자료 확인일: 2026-10-26.

`web/dist/data.js`에 기록과 22개 원자료, `web/dist/catalog.js`에 편집 분류가 있습니다. 사진의 저작자·원본·라이선스는 `web/dist/assets/credits.json` 및 웹 자료실에서 확인합니다. 직접 제작한 개념도는 실측도나 학술 복원도가 아닙니다. 사진 11장은 외부 이미지 서버에 의존하지 않고 함께 배포합니다.

## 검증

```sh
npm run build
npm run check
npm run verify:deployment
```

`check`는 생성한 HTML, 내부 링크, 출처·이미지 파일, 중복 HTML/SVG 식별자, 모듈 연결, 분류별 기록과 필터·페이지 번호를 검사합니다. `verify:deployment`는 Vercel 게시본의 모든 정상 페이지, 전체 사진·아이콘, JS·CSS의 HTTP 응답과 SHA-256, 슬래시 없는 주소의 이동, 잘못된 주소의 복구 화면을 검사합니다. 다른 Vercel 배포는 `npm run verify:deployment -- https://배포주소.vercel.app`으로 확인합니다.

보관함과 메모는 현재 브라우저에만 저장되며 서버로 전송되지 않습니다.
