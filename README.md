# 기억 — 한국건축 아카이브

구석기부터 동시대까지 한국 건축·생활문화·지역 특색을 비교하는 한국어 학습 웹사이트입니다.

게시 사이트: [기억 — 한국건축 아카이브](https://gieok-korean-architecture.hopesound.chatgpt.site) · 비공개, 소유자 ChatGPT 로그인 필요

## 실행

Node.js 22 이상에서 별도 패키지 설치 없이 실행합니다.

```sh
npm run dev
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다. 정적 배포 대상은 `site/dist/`입니다.

## 기능

- 10개 시대·6개 권역, 23개 건축 기록의 시대·용도별 탐색
- 자료 출처, 창건·재건 구분, 복원·개념도 안내가 포함된 상세 기록
- 시대·건물 선택 및 재료·구조·공간·문화의 비교표
- 전역 검색, 브라우저에 저장하는 보관함과 관찰 메모
- 공공기관 원자료 22개, 건축 용어집, 해설이 있는 학습 퀴즈
- 모바일 레이아웃, 키보드 탐색, 비교표 인쇄

## 자료와 이미지

내용은 국립중앙박물관, 국가유산청, 국사편찬위원회, 서울역사박물관, 속초시립박물관, UNESCO 등의 공개 자료를 요약·재구성했습니다. 전수조사가 아닌 대표 사례 기반의 학습용 아카이브입니다. 자료 확인일: 2026-10-26.

`site/dist/data.js`에 기록과 출처가 있습니다. `site/dist/assets/credits.json`과 웹 자료실에서 사진별 저작자·원본·라이선스를 확인할 수 있습니다. 개념도는 직접 제작한 설명용 도식으로 실측도나 학술 복원도가 아닙니다. 사진 다운로드 스크립트는 일반 실행에 필요하지 않습니다.

## 검증

```sh
npm run check
```

스크립트 문법, 시대·권역의 기록 유무, 출처 연결, 이미지 파일과 저작권 표기, 퀴즈 데이터를 확인합니다. 보관함과 메모는 현재 브라우저에만 저장되며 서버로 전송되지 않습니다.
